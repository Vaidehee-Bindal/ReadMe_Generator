# GitHub README Generator

A privacy-first README.md generator built with React, TypeScript, and Vite. It scans local folders or public GitHub repositories, detects tech stack and project structure, then generates a polished README with live preview, templates, history, and export controls.

## Features

- Local folder scanning in the browser
- Public GitHub repository scanning
- Heuristic tech stack and feature detection
- README templates for modern, detailed, minimal, and open-source projects
- Light and dark mode
- Copy, fullscreen preview, and README.md download
- Local browser history

## Development

```bash
npm install
npm run dev
```

## Testing
